# AI Recipe Generator - Full Stack Application

A full-stack web application that generates custom recipes based on the ingredients you have in your fridge.

## 🚀 Live Demo
[Click here to view the live app](https://ai-recipe-app-inky.vercel.app/)

## 🛠️ Tech Stack
- **Frontend:** React, Vite, CSS
- **Backend:** Node.js, Express
- **AI Integration:** Groq API (Llama 3)
- **Deployment:** Vercel (Frontend) + Render (Backend)

## ✨ Features
- Input ingredients you have on hand
- AI generates a custom recipe with a title, ingredients list, and step-by-step instructions
- Loading state while the AI is "thinking"
- Error handling for invalid responses
